# PDI's Doxygen XML

The site renders [PDI](https://github.com/pdidev/pdi)'s reference in fourteen versions
(`content/_content.gotmpl`). Each directory is Doxygen 1.18.0's XML output, generated by
`../../generate-pdi-xml.sh PDI_SOURCE_DIR TAG NAME` with PDI's own documentation configuration, as
XML only and with `XML_PROGRAMLISTING=NO`.

The script checks the tag out in a temporary worktree and configures it with CMake, with the
documentation on and everything else that can be off turned off, which writes the Doxyfile and the
generated headers that it lists as inputs:

```sh
cmake -S pdi -B BUILD -DBUILD_DOCUMENTATION=ON -DBUILD_TESTING=OFF -DBUILD_FORTRAN=OFF \
  -DBUILD_BENCHMARKING=OFF -DBUILD_PYTHON=OFF
```

Doxygen then runs on it from the directory that PDI's `doc` target runs it from.

## Adjustments for Doxygen 1.18

- None of the Doxyfiles needed a change. Doxygen 1.18.0 warns that `DOT_MULTI_TARGETS` is obsolete
  in all of them, and ignores it.
- A release configured with `BUILD_FORTRAN=OFF` has no Fortran interface in its pages when its
  `pdif.h`, which zpp generates, is an input of the Doxyfile: Doxygen warns that the input is
  missing and skips it (1.0 to 1.7 do). 1.8 to 1.10 can't configure without Fortran, and are
  configured with `BUILD_FORTRAN=ON` (the script retries by itself), which gives their Fortran
  pages. The vendored zpp of 1.8 predates CMake 4: `CMAKE_POLICY_VERSION_MINIMUM=3.5`.
- The tutorial's `README.md` is missing from the releases before 1.12 (a Doxygen warning): they
  have no Hands-on page, and only the latest release's tutorial is rendered.

## Hand edits

Regenerating a directory drops these edits: make them again, each in its own commit.

- `pdi-1.12/`: the page `serialize_plugin` (the Serialize plugin) is removed, so that a page of
  `main` has no twin in the latest release. Its file, its `index.xml` entry, its `innerpage` in
  `Plugins.xml`, and its row of the plugin table in `Plugins.xml` (whose `rows` goes from 11 to
  10) are gone. Every other version has the page, since `main` was 14 commits past 1.12.0 and
  no page of `main` was missing from 1.12. The version menus show it: the page of 1.12 falls
  back to the Plugins page.
